# 모의 면접 준비

주소 `/interviews/new` · 이슈 [#27](https://github.com/likelion-backendschool-9th/answerfit/issues/27)

## 시나리오

- `#27-S1` 면접 정보 단계에서 진행 방식 → 질문 수 → 면접 유형 → 영상 보관 기간 → (경험 면접이면) 서류 그룹 순서로 고르고, 아래 버튼 영역의 "다음 · 환경 점검"을 누른다.
- `#27-S2` 면접 유형 네 가지(경험, CS, 인성·컬쳐핏, PT)를 모두 고를 수 있다.
- `#27-S3` 영상 보관 기간은 "2026년 12월 10일 (목)"과 남은 일수(D-15)로 보인다. 누르면 브라우저 달력이 열린다.
- `#27-S4` 환경 점검 단계에서 왼쪽 카메라 미리보기와 얼굴 가이드, 오른쪽 체크리스트(카메라, 마이크, 얼굴 인식, 시선 분석), 마이크 입력 막대, "질문 음성 미리 듣기"를 본다.

## 정한 것

- 오른쪽 요약 카드는 없앴다. 본문을 넓게 쓰고, 버튼과 오류 문구는 본문 아래 버튼 영역에 둔다. (#27, 2026-11-26)
- 영상 보관 기간은 모든 면접 유형에 쓴다. 서류 그룹을 고르면 그 그룹의 면접일이 기본값이 된다. 비우면 면접일부터 30일 뒤 삭제한다. (#27, 2026-11-26)
- 인성·컬쳐핏, PT 면접은 고를 수 있게 열었다. 질문 생성은 아직 없어 목업 질문 은행으로 진행한다. (#27, 2026-11-26)
- 마이크는 한 번이라도 소리가 들어오면 "입력 정상"으로 본다. 얼굴 인식과 시선 분석은 `isGazeReady`가 거짓이면 "준비 중"으로 보인다. (#27, 2026-11-26)
- 준비 화면에는 사이트 푸터를 그린다. 면접실(`/interviews/[id]`)은 그대로 푸터가 없다. (#27, 2026-11-26)
