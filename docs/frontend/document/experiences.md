# 경험 정리 (`/experiences`)

이슈: #17 · 백엔드: [document 도메인](../../backend/document/README.md)

## 요구사항과 시나리오

- S1. 헤더 메뉴 "경험 정리"를 누르면 경험 목록이 열린다. 데스크톱에서는 엑셀처럼 셀을 골라 고치는 표다.
- S2. "+ 경험 추가"나 표 맨 아래 "+ 새 행 추가"를 누르면 맨 아래에 새 행이 생기고 제목 셀을 바로 편집한다. 걸려 있던 필터는 풀린다(새 행이 가려지지 않게).
- S3. 제목·소속·역할은 셀 안에서 적고, 구분·기간·태그·성과는 셀을 누르면 팝오버가 열린다. 방향키로 움직이고 Enter로 편집, Tab은 다음 칸, Esc는 취소다. 셀을 고른 채 글자를 치면 그 글자로 편집을 시작한다.
- S4. 셀을 고치면 그 행을 바로 저장한다. 저장하는 동안 셀 오른쪽에 스피너, 끝나면 체크가 잠깐 보인다. 실패하면 셀에 빨간 테두리와 오류 안내가 뜬다.
- S5. 제목이 없는 행은 저장하지 않고 제목 셀이 오류로 알린다. 종료일이 시작일보다 빠르면 적용할 수 없다. 종료일을 비우면 "진행 중"으로 보인다.
- S6. 활동 내용이 비어 있는 행은 번호 왼쪽에 주황 점이 있다. 활동 내용은 행 끝의 ▸로 여는 오른쪽 상세 패널에서 적는다.
- S7. ⋯ 메뉴로 행을 복제하거나 삭제한다. 삭제는 한 번 더 묻는다.
- S8. 엑셀·구글 시트에서 복사한 행을 "붙여넣기로 가져오기"로 한꺼번에 넣는다. 열 순서는 표와 같고, 제목이 없는 줄은 건너뛴다.
- S9. "역량 매트릭스" 탭은 경험(행) × 쓰인 태그(열)로, 어떤 역량을 뒷받침할 경험이 있는지 보여 준다.
- S10. 모바일(40rem 미만)에서는 표 대신 카드 목록이 보이고, 카드를 누르면 상세 화면(`/experiences/[id]`)으로 간다. 새 경험은 `/experiences/new`에서 적는다.

## 정한 것

- 표에서 고친 값은 서버 목록을 다시 불러오지 않고 화면 상태에 바로 반영한다. 셀마다 다시 불러오면 저장 중인 다른 행의 입력이 덮이기 때문이다. 모바일 상세 화면에서 저장하고 돌아올 때만 다시 불러온다.
- 새 행의 아이디는 화면이 만들고(`crypto.randomUUID`), 저장은 아이디로 만들거나 고치는 한 가지 요청이다. 제목을 적기 전의 빈 행을 서버에 만들지 않기 위해서다.
- 팝오버는 표의 스크롤 상자에 잘리지 않도록 `body`에 그리고, 스크롤하면 닫는다. 기간·성과 팝오버는 바깥을 누르면 적은 내용을 저장하고, Esc만 취소다.
- 기간 달력은 브라우저 날짜 입력을 쓴다.

## 가정

- 백엔드 API는 아직 없다. 화면은 아래 형식을 가정하고, 시연 데이터 모드에서는 방문자별 메모리 저장소를 쓴다.
  - `GET /api/v1/experiences` → `Experience[]`
  - `PUT /api/v1/experiences/{id}` (본문 `Experience`) → 만들거나 고침
  - `DELETE /api/v1/experiences/{id}` → 없는 아이디(저장 전 행)는 404이고 화면은 성공으로 본다
  - `Experience`: `id`, `title`, `type`(`ActivityType`, 없으면 null), `startedOn`·`endedOn`(YYYY-MM-DD, 없으면 null), `organization`, `role`, `tags`, `content`, `result`
- 사기업 태그 10개(도전정신, 책임감, 협업, 리더십, 소통, 창의성, 전문성, 고객지향, 주도성, 분석력)는 임시다. 공기업은 NCS 직업기초능력 10개다.

## 아직 정하지 않은 것

- [ ] `user_experiences`에 소속·역할 열이 없다. 표에는 있으므로 백엔드에 열을 더하거나 화면에서 뺀다.
- [ ] `user_experiences.content`는 NOT NULL·필수지만, 화면은 활동 내용 없이 저장하고 주황 점으로 알린다. 백엔드에서 필수를 풀어야 한다.
- [ ] 엔티티의 `competencies`와 화면의 태그가 같은 것인지.
- [ ] 붙여넣기는 행마다 저장 요청을 보낸다. 일괄 저장 API가 생기면 바꾼다.

## 참고

- 한글 입력 중의 Enter는 조합을 끝내는 키라서, 셀 입력창은 `isComposing`일 때 Enter를 무시한다. 셀을 고른 상태에서 한글을 치면 첫 글자가 IME에 먹혀 편집이 시작되지 않으니 Enter로 편집을 연다.
