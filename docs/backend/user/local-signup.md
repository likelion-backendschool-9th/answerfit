# 이메일 회원가입

- `GET /api/v1/auth/email-availability`는 기존 가입 폼의 이메일 사전 확인에 사용한다. 최종 가입에서도 이메일과 닉네임의 중복을 확인한다.
- `POST /api/v1/auth/signup`은 multipart로 이메일, 비밀번호, 닉네임, 서비스 이용약관·개인정보 수집·면접 녹화 필수 동의와 선택 사진을 받는다. 가입 성공은 공통 응답 형식의 201을 반환한다. 이메일 로그인과 토큰 발급은 별도 기능이다.
- 필수 동의 3종을 가입 시 검증한다. 동의 이력 저장은 데이터 모델을 확정한 뒤 구현한다.
- 사진은 최대 5MB의 JPEG·PNG를 받아 회원과 같은 트랜잭션에서 저장한다. 사진 없이 가입하면 이미지 키가 비어 있어 기본 로고를 사용한다. 저장한 사진의 조회·표시는 프로필 기능의 범위다.
- PostgreSQL 환경에서는 `users` 테이블을 준비한 뒤 [가입 스키마 SQL](../../../backend/sql/local-signup-postgresql.sql)을 적용한다. 탈퇴 회원을 제외하는 이메일·닉네임 유니크 인덱스가 동시 가입의 최종 중복을 방지한다. 기존 회원 데이터에 중복이 있으면 해당 데이터를 정리한 후 적용한다.
